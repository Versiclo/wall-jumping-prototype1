## Playtest Logging — What You Should Know

Thanks for testing the game! While you play, the game quietly records some data about your session to a local file. This note explains exactly what's recorded, where to find it when you're done and how to send it back.

### What's recorded

- Your character's position, sampled a few times per second, for the whole session.
- Every death (where and when it happened).
- Nothing else. No inputs, no screen recording, no personal information — just position/time data tied to a random anonymous ID generated by your device, not your name.

This lets me reconstruct the exact path you took through the level afterward, see where you paused or hesitated, and see where deaths clustered — without needing to watch over your shoulder while you play.

### Where to find the log file

The game writes a `.csv` file to:

```
%USERPROFILE%\AppData\LocalLow\Versiclo\Restless Square\PlaytestLogs
```

Fastest way to get there: paste the address above into a Windows Explorer address bar or run it via `Win + R`.

Files are named like `playtest_<id>_<date>_<time>.csv` — if you play multiple sessions, you'll get one file per session. Please send all of them back.

### Sending it back

Just grab the `.csv` file or compress them if there are more than one (zip, rar or any other compression method).
- You can send it via the [Google Form](https://forms.gle/iAL3E7P1J1U4Fss47)
- Or email me directly versiclo@google.com
